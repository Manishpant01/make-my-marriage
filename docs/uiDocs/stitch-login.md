# Stitch prompt — log in and sign up

Follow [typography.md](typography.md) for the approved Outfit + Fraunces font system; it overrides older font-family instructions in this prompt.

For application animations, follow [animations.md](animations.md): a coherent form entrance and short delayed photograph fade, preserving autofill, validation, and mobile behavior.

Paste this into Stitch as a new design. Match the landing page that already exists. Do not redesign the landing page.

## Prompt

Design the log in and create-account screens for MakeMyMarriage. Match the landing page already designed: same logo, same ivory background, same near-black text, same bronze, same modern grotesque type, same slightly rounded buttons. English only.

Make four frames:
1. Log in, desktop, 1440 wide
2. Log in, mobile, 390 wide
3. Create account, desktop, 1440 wide
4. Create account, mobile, 390 wide

The screens should feel calm, premium, and quiet. A person should see the form immediately. No feature list, no testimonials, no social login.

Logo: the wordmark “MakeMyMarriage” in the modern grotesque, near-black, with the small bronze open circle to its left. Same mark as the landing page.

Color, nothing else:
- Background: warm ivory #F6F3EE
- Text: near-black #1C1917
- Secondary text: warm gray #6B6560
- Buttons: muted bronze #8C6A45, label #FFFcf8
- Input borders and hairlines: #E7E1D8
- Input fill: #FFFcf8

Buttons and inputs use a small corner radius, about 8px. Not a pill. Not a sharp square.

Desktop, both pages: split the frame. The left half is one photograph, full height, no frame, no border, no browser window, no laptop mock. Use the same kind of photograph as the landing page: editorial, natural warm light, quiet, the couple’s hands or a calm daylight scene. No stage, no crowd, no red-and-gold decor. The right half is ivory, with the form centered vertically. The form is narrow, about 360 wide. One photograph on the desktop frames only. Do not add a second image.

Mobile, both pages: no photograph. The form sits on the ivory background with comfortable side margins. The logo is at the top. Touch targets are easy to tap. Text does not overflow.

Log in form, top to bottom:
- Logo
- Title: “Log in”
- Label “Email”, then the field
- Label “Password”, then the field
- A quiet text link: “Forgot password”
- Bronze button: “Log in”
- One line: “New here?” then the text link “Create an account”

Create account form, top to bottom:
- Logo
- Title: “Create an account”
- Label “Name”, then the field
- Label “Email”, then the field
- Label “Password”, then the field
- Bronze button: “Create account”
- One line: “Already have an account?” then the text link “Log in”

Labels sit above the fields, in the near-black. Fields are empty, with no sample text inside them.

Do not add Google, Apple, or any other sign-in. Do not add icons, illustrations, a fake browser, a phone frame, prices, or extra copy. Do not change the colors.
