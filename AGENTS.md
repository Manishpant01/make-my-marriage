# MakeMyMarriage

Product decisions live in `docs/`. What is already built lives in `docs/project-status.md`. Read that file before starting work.

## Project status

When a feature is built and in the repo, update `docs/project-status.md` in the same change:

1. Rewrite **Now** so it matches what exists.
2. Add a log entry at the top of **Log**, with the date, the feature name, and what landed.

Log a feature when it is in the codebase. A design, a prompt, or a plan is not a log entry. A small fix inside a feature already listed does not need its own entry.
